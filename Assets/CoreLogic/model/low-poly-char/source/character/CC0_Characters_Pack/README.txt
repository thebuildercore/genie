CC0 BLOCKY CHARACTERS PACK  -  5 rigged + animated low-poly characters
=====================================================================

FILES
- CC0_Blocky_Characters_Pack.glb  -> all 5 characters in one scene, 5 animations
- CC0_Bolt.glb, CC0_Nova.glb, CC0_SirBlocks.glb, CC0_Scout.glb, CC0_Merlo.glb -> each character on its own
- CC0_Characters_WORKFILE.blend -> Blender source (scene "CC0_Characters"; build scripts are inside as text blocks)

WHAT'S INSIDE
- Bolt (robot), Nova (astronaut), Sir Blocks (knight), Scout (explorer), Merlo (wizard)
- ~1.1k-1.3k triangles each (6,170 for the whole pack). Flat-shaded, solid-colour PBR materials, no textures needed.
- Shared 9-bone skeleton: Hips, Torso, Head, Arm.L, Arm.R, Leg.L, Leg.R, Foot.L, Foot.R (rigid skinning, 1 bone per vertex)
- 5 animations on every character (30 fps): Idle (loop), Walk (loop), Run (loop), Wave (one-shot), Jump (one-shot)
- Units: metres, Y-up in the glTF files, characters face +Z. Feet sit on the floor at height 0.
- Original designs. No third-party assets, no trademarks, no textures from anywhere else.
